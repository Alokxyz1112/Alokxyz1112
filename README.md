I'm Alok. Biotech student. I learn bioinformatics, build Android apps, and send small fixes to the Flutter and Dart docs.

Right now I'm building [**Vedrino**](https://vedrino.website), a focus app for Android. My study days kept slipping into Shorts and Reels, so I'm making the app I wanted for myself. Plan less. Flow more. Beta in December.

<a href="https://vedrino.website"><picture><source media="(prefers-color-scheme: dark)" srcset="assets/vedrino-dark.svg"><img src="assets/vedrino-light.svg" width="100%" alt="A Reels feed on a phone scrolls, stops, and turns into a 25 minute focus timer that says: Not now. You've got this."></picture></a>

<details>
<summary><b>What already works</b></summary>
<br/>

- Block just the Shorts and Reels inside an app and keep the rest. Messages still come through, long videos still play.
- Or block the whole app, set daily limits, block websites, run schedules, or go strict.
- Hit a wall and you get a calm screen: "Not now. You've got this." One five minute pause per session.
- Timers with no buttons. Stopwatch, Timer, Pomodoro and Clock, full screen. 20 clock faces, 12 calm chimes.
- Chat with friends and groups that stays quiet while you focus.

All of this runs in my test build.

</details>
